# Написание торговых стратегий — Rawanga Trading Desk

Добро пожаловать! Это руководство объясняет, как писать, тестировать и делиться
своими стратегиями и индикаторами в **Rawanga Trading Desk** — портативном
терминале графиков и сигналов.

Стратегия — это **обычный векторный код на Python**. Ничего устанавливать не надо,
не нужно ничего импортировать: вы пишете несколько строк во встроенном редакторе,
а движок прогоняет их по данным цены.

---

## 1. Введение — что такое стратегия?

**Стратегия** — это небольшой фрагмент **векторного кода на Python**, который
движок терминала выполняет на каждом баре графика.

- «Векторный» означает, что вы работаете **с целыми столбцами данных сразу**, а не
  с циклами. Вместо *«для каждой свечи сделай…»* вы пишете выражения, которые
  применяются ко всей серии одной строкой.
- Движок даёт готовые **серии**: `open`, `high`, `low`, `close`, `volume`. Каждая —
  это `pandas.Series`, выровненная по свечам графика.
- Вы описываете **когда входить** (`entry(...)`) и **когда выходить** (`exit(...)`),
  и/или **что рисовать** на графике (`plot(...)`, `shape(...)`, `hline(...)`).

Результат стратегии — набор баров, где `long`, `short` и `exit` равны `True`.
Ровно эти бары использует бэктест и планировщик реального времени.

> В редакторе можно запускать код двух видов:
> - **стратегия** — объявляет входы/выходы (Compile → регистрируется в движке);
> - **индикатор** — только рисует (To chart → наложение на график).
> Один и тот же код может делать и то, и другое.

## 2. Доступные имена (полный API)

Все эти имена уже определены. Их не нужно импортировать — просто используйте.

### Серии (данные цены)

| Имя | Тип | Значение |
|-----|-----|----------|
| `open`   | `pandas.Series` | Цена открытия каждого бара |
| `high`   | `pandas.Series` | Максимум |
| `low`    | `pandas.Series` | Минимум |
| `close`  | `pandas.Series` | Цена закрытия |
| `volume` | `pandas.Series` | Объём |

У всех серий общий индекс (метки времени свечей), поэтому их можно напрямую
сравнивать и комбинировать.

### Входы (параметры пользователя)

```python
value = inp(name, default, title='', type='float')
```

Объявляет **настраиваемый параметр**, который появляется в панели настроек.
Возвращает текущее значение параметра.

- `name` — внутренний ключ (строка), например `'fast'`.
- `default` — значение по умолчанию.
- `title` — понятная подпись в интерфейсе (необязательно).
- `type` — одно из `'int'`, `'float'`, `'bool'`, `'string'` (по умолчанию `'float'`).

```python
fast  = inp('fast', 12, 'Быстрая EMA', 'int')
mult  = inp('mult', 1.5, 'Множитель объёма', 'float')
enabled = inp('enabled', True, 'Использовать фильтр', 'bool')
label = inp('label', 'MACD', 'Подпись серии', 'string')
```

Редактор сам сканирует код и показывает каждый `inp(...)`, записанный в одну
строку, отдельной настройкой. Всегда присваивайте результат переменной:

```python
period = inp('period', 14, 'Период RSI', 'int')   # ✅ хорошо
inp('period', 14, 'Период RSI', 'int')            # ❌ значение теряется
```

### Индикаторы

Все индикаторы возвращают `pandas.Series` (или кортеж из них), выровненные по
графику.

| Функция | Возвращает | Примечания |
|---------|-----------|------------|
| `sma(a, n)` | Series | Простая скользящая средняя |
| `ema(a, n)` | Series | Экспоненциальная скользящая средняя |
| `rma(a, n)` | Series | Сглаживание Уайлдера (используется в RSI/ATR) |
| `wma(a, n)` | Series | Взвешенная скользящая средняя |
| `stdev(a, n)` | Series | Скользящее стандартное отклонение |
| `highest(a, n)` | Series | Максимум за `n` баров |
| `lowest(a, n)` | Series | Минимум за `n` баров |
| `change(a)` | Series | Разница с предыдущим баром |
| `rsi(a, n=14)` | Series | Индекс относительной силы |
| `macd(a, fast=12, slow=26, signal=9)` | `(macd, signal, hist)` | Линия MACD, сигнальная, гистограмма |
| `bb(a, n=20, k=2.0)` | `(upper, basis, lower)` | Полосы Боллинджера |
| `atr(n=14)` | Series | Средний истинный диапазон (использует high/low/close) |
| `supertrend(period=7, mult=2.5)` | `(direction, line)` | `direction`: `+1` вверх / `-1` вниз |
| `adx(di_len=14, smooth=14)` | `(plus_di, minus_di, adx)` | Сила тренда |
| `donchian(n=10)` | `(upper, lower)` | Канал Дончиана |

Примеры:

```python
ma = sma(close, 50)
er = ema(close, 21)

# MACD -> (macd, signal, hist)
m = macd(close)
macd_line   = m[0]
macd_signal = m[1]
macd_hist   = m[2]

# Bollinger -> (upper, basis, lower)
b = bb(close, 20, 2.0)
bb_upper = b[0]
bb_basis = b[1]
bb_lower = b[2]

# Supertrend -> (direction, line)
st = supertrend(7, 2.5)
st_dir  = st[0]
st_line = st[1]

# ADX -> (plus_di, minus_di, adx)
a = adx(14, 14)
plus_di  = a[0]
minus_di = a[1]
adx_val  = a[2]

# Donchian -> (upper, lower)
d = donchian(10)
don_hi = d[0]
don_lo = d[1]
```

> `atr`, `supertrend`, `adx` и `donchian` читают `high`/`low`/`close` внутри себя —
> вы передаёте только параметры периода.

> ℹ️ **Индикаторы с несколькими значениями возвращают кортеж.** Доступ к частям —
> по **индексу**: `m[0]`, `m[1]`, … — или сразу, например `macd(close)[2]`.
> **Распаковка кортежа** (`a, b = f(...)`) в песочнице **запрещена** — она будет
> отклонена при **Check** (см. «Частые ошибки», §10).

### Сравнения (пересечения)

```python
crossover(a, b)   # True на баре, где a пересекает b СНИЗУ ВВЕРХ
crossunder(a, b)  # True на баре, где a пересекает b СВЕРХУ ВНИЗ
```

`a` и `b` могут быть серией или числом. Возвращает булеву серию.

```python
entry('long',  crossover(ema_fast, ema_slow))
entry('short', crossunder(ema_fast, ema_slow))
```

### Прочее

| Функция | Возвращает | Значение |
|---------|-----------|----------|
| `nz(x, repl=0)` | Series/скаляр | Заменить `NaN` на `repl` |
| `na(x)` | bool / bool-серия | `True` там, где значение `NaN` |
| `series(x)` | Series | Превратить скаляр/массив в Series по графику |

```python
r_clean = nz(rsi(close, 14), 50)   # NaN в начале → 50
is_missing = na(close)
```

### Сигналы

```python
entry(side, cond)   # side: 'long' или 'short'
exit(cond)
```

- `entry('long', cond)` — открыть/развернуть в **лонг**, когда `cond` истинно.
- `entry('short', cond)` — открыть/развернуть в **шорт**, когда `cond` истинно.
- `exit(cond)` — **закрыть** текущую позицию, когда `cond` истинно.

`cond` должна быть булевой серией (результатом сравнения). Пока условие не
сработало, ничего не отправляется.

```python
entry('long',  crossover(ema_fast, ema_slow))
entry('short', crossunder(ema_fast, ema_slow))
exit(crossunder(close, ema_slow))
```

### Отрисовка (вывод индикатора)

```python
plot(title, series, color='#2962ff', width=1, style='line')
shape(title, cond, color, location='abovebar', shape='circle')
hline(title, value, color)
```

| Функция | Назначение |
|---------|------------|
| `plot(...)` | Нарисовать линию (или гистограмму) по серии |
| `shape(...)` | Нарисовать маркер на барах, где `cond` истинно |
| `hline(...)` | Нарисовать горизонтальный уровень (например, 30 / 70 для RSI) |

- `plot`: `style` — `'line'` (по умолчанию) или `'histogram'`; `width` — толщина
  линии (1–4).
- `shape`: `location` — `'abovebar'` или `'belowbar'` (также `'top'`/`'bottom'`);
  `shape` — `'circle'`, `'triangleup'`, `'triangledown'` или `'square'`.
- `hline`: `value` — цена/уровень горизонтальной линии.

```python
plot('SMA 50', sma(close, 50), '#ff9800', 2, 'line')
plot('Гист. MACD', macd(close)[2], '#26a69a', 1, 'histogram')
hline('Ноль', 0, '#787b86')
shape('Buy',  crossover(close, sma(close, 50)), '#26a69a', 'belowbar', 'triangleup')
shape('Sell', crossunder(close, sma(close, 50)), '#ef5350', 'abovebar', 'triangledown')
```

## 3. Как писать условия

Сравнение серий даёт **булеву серию** — одно значение `True`/`False` на бар:

```python
bull = ema_fast > ema_slow
oversold = rsi(close, 14) < 30
strong = atr(14) > 1.5
```

Чтобы объединять условия, используйте **побитовые операторы** — они работают
поэлементно по всей серии:

| Что нужно | Оператор | Пример |
|-----------|----------|--------|
| И | `&` | `(ema_fast > ema_slow) & (volume > vol_ma)` |
| ИЛИ | `\|` | `(r < 30) \| (r > 70)` |
| НЕ | `~` | `~(ema_fast > ema_slow)` |

> ⚠️ **НЕ используйте `and`, `or`, `not` для серий.** Операторы `and`/`or`/`not` в
> Python рассчитаны на одно значение истинности и вызовут ошибку
> (*«The truth value of a Series is ambiguous»*). Всегда оборачивайте каждое
> сравнение в скобки и соединяйте их через `&`, `|`, `~`:

```python
# ✅ правильно
cond = (ema_fast > ema_slow) & (rsi(close, 14) < 55)

# ❌ неверно — вызовет ошибку
cond = (ema_fast > ema_slow) and (rsi(close, 14) < 55)
```

Всегда ставьте скобки вокруг отдельных сравнений: в Python `&` связывает "сильнее"
чем `>`:

```python
# ✅
bull = (ema_fast > ema_slow) & (close > ema_fast)

# ❌ разберётся как ema_fast > (ema_slow & close) > ema_fast
bull = ema_fast > ema_slow & close > ema_fast
```

Можно свободно сравнивать серию с числом или две серии между собой.

## 4. Правила песочницы (безопасность)

Ваш код выполняется в **ограниченной песочнице**. Перед запуском код проверяется
(AST-белый список): он должен быть безопасным и чисто векторным.

**Запрещено — будет отклонено до запуска:**

- `import` / `from ... import ...`
- `eval`, `exec`, `open`
- любой доступ к файлам или сети
- циклы: `for`, `while`
- генераторы и списковые/множественные/словарные включения
  (`[... for ...]`, `(... for ...)`)
- определения функций/классов/lambda (`def`, `class`, `lambda`)
- `with`, `try`/`except`, `raise`, `yield`, `await`
- `global`, `nonlocal`, `del`
- **dunder-атрибуты** — всё, что начинается с `__` (например `__class__`,
  `__globals__`)

**Разрешено — безопасные векторные «кирпичики»:**

- Все имена API выше (`sma`, `ema`, `rsi`, `entry`, `plot`, …).
- Безопасные **методы Series/DataFrame**, включая (не исчерпывающе):
  `shift`, `fillna`, `ffill`, `bfill`, `dropna`, `interpolate`,
  `rolling`, `ewm`, `expanding`, `mean`, `sum`, `std`, `var`, `min`, `max`,
  `median`, `abs`, `clip`, `where`, `diff`, `cumsum`, `cummax`, `cummin`,
  `cumprod`, `pct_change`, `astype`, `isna`, `notna`, `rank`, `round`,
  `pow`, `replace`, `any`, `all`, `count`, `first`, `last`, `head`, `tail`,
  `idxmin`, `idxmax`, а также методы-операторы `le`, `ge`, `lt`, `gt`, `eq`, `ne`,
  `add`, `sub`, `mul`, `div`, `mod`.
- Помощники **numpy** через `np.`: `np.maximum`, `np.minimum`, `np.where`,
  `np.abs`, `np.log`, `np.log10`, `np.sqrt`, `np.exp`, `np.clip`, `np.sign`,
  `np.nan_to_num`, `np.isnan`, `np.isfinite`, `np.arange`.
- Встроенные: `bool`, `float`, `int`, `abs`, `round`, `min`, `max`, `len`.
- `df` (полный DataFrame OHLCV), `pd`, `np`.

**Полезно знать:**

- Поскольку значения векторные, `if` по серии не работает. Вместо ветвления
  используйте `np.where` / `.where(...)`:

```python
# ❌ if по серии — неоднозначно
# if close > open: ...

# ✅ векторный выбор
direction = np.where(close > open, 1, -1)
stop = np.minimum(close, ema(close, 20))   # поэлементный минимум
```

- Только доступ на чтение. Никаких побочных эффектов, ввода-вывода, сохранений.

## 5. Пошаговый пример №1 — EMA-кроссовер

Идея: входить в **лонг**, когда быстрая EMA пересекает медленную снизу вверх, и в
**шорт**, когда она пересекает снизу вниз (сверху вниз).

```python
# ── Входы ─────────────────────────────────────────────────
fast = inp('fast', 12, 'Быстрая EMA', 'int')
slow = inp('slow', 26, 'Медленная EMA', 'int')

# ── Индикаторы ───────────────────────────────────────────
ema_fast = ema(close, fast)
ema_slow = ema(close, slow)

# ── Сигналы ──────────────────────────────────────────────
entry('long',  crossover(ema_fast, ema_slow))
entry('short', crossunder(ema_fast, ema_slow))
```

Разбор построчно:

1. `fast` / `slow` — два параметра, которые можно менять в панели настроек.
2. `ema(...)` — считаем две средние сразу по всему графику.
3. `entry('long', ...)` — лонг срабатывает ровно на баре, где быстрая линия
   пересекает медленную снизу вверх.
4. `entry('short', ...)` — симметрично: шорт на пересечении сверху вниз.

Необязательные дополнения:

```python
# Торгуем только когда волатильность осмысленна
filter_ok = atr(14) > sma(atr(14), 20)

entry('long',  crossover(ema_fast, ema_slow) & filter_ok)
entry('short', crossunder(ema_fast, ema_slow) & filter_ok)

# Выход в кэш при развороте тренда
exit(crossunder(ema_fast, ema_slow))
```

## 6. Пошаговый пример №2 — разворот по RSI

Идея: покупать, когда RSI перепродан, продавать, когда перекуплен.

```python
# ── Входы ─────────────────────────────────────────────────
n  = inp('n', 14, 'Период RSI', 'int')
lo = inp('lo', 30, 'Перепроданность', 'float')
hi = inp('hi', 70, 'Перекупленность', 'float')

# ── Индикатор ────────────────────────────────────────────
r = rsi(close, n)

# ── Сигналы ──────────────────────────────────────────────
entry('long',  r < lo)
entry('short', r > hi)
```

Пояснение:

1. `rsi(close, n)` даёт серию RSI.
2. `r < lo` истинно на каждом баре, где RSI ниже 30 → лонг.
3. `r > hi` истинно на каждом баре, где RSI выше 70 → шорт.

> `r < 30` остаётся `True` на многих барах подряд, пока RSI перепродан. Слой
> сигналов движка «сворачивает» серию одинаковых сигналов, поэтому новой сделки на
> каждой свече не будет. Если нужен только *первый* заход ниже 30, добавьте
> пересечение:

```python
entry('long',  crossover(r, lo))
entry('short', crossunder(r, hi))
```

Добавим трендовый фильтр, чтобы не ловить «падающие ножи»:

```python
uptrend = close > sma(close, 200)
entry('long',  (r < lo) & uptrend)
entry('short', (r > hi) & ~uptrend)
```

## 7. Пример индикатора (только отрисовка)

Индикатор не торгует — он только рисует. Используйте его кнопкой **To chart**.

```python
# ── Входы ─────────────────────────────────────────────────
n = inp('n', 50, 'Период SMA', 'int')

# ── Расчёт ───────────────────────────────────────────────
ma = sma(close, n)

# ── Отрисовка ────────────────────────────────────────────
plot('SMA', ma, '#ff9800', 2, 'line')
hline('Ноль', 0, '#787b86')
shape('Buy',  crossover(close, ma), '#26a69a', 'belowbar', 'triangleup')
shape('Sell', crossunder(close, ma), '#ef5350', 'abovebar', 'triangledown')
```

Что появится на графике:

- оранжевая **линия** SMA(50);
- серая пунктирная **горизонтальная линия** на уровне 0;
- зелёные маркеры-**треугольник вверх** под барами на пересечениях закрытия вверх
  через SMA;
- красные маркеры-**треугольник вниз** над барами на пересечениях вниз.

Панель RSI выглядит так:

```python
n = inp('n', 14, 'Период RSI', 'int')

r = rsi(close, n)

plot('RSI', r, '#9c27b0', 2, 'line')
hline('Перекупленность', 70, '#ef5350')
hline('Перепроданность', 30, '#26a69a')
```

## 8. Экспорт / импорт — как делиться стратегиями

Каждую скомпилированную стратегию можно скачать одним файлом **`.rwd.json`** и
передать кому угодно; получатель импортирует её в один клик.

- Кнопка **Export** → скачивает `<Title>.rwd.json` для выбранной стратегии.
- Кнопка **Import** → выберите файл `.rwd.json` → стратегия проверяется и сразу
  регистрируется.

Файл — это обычный JSON такой структуры:

```json
{
  "kind": "rawanga-trading-desk-strategy",
  "version": 1,
  "key": "my_strategy",
  "title": "My Strategy",
  "source": "fast = inp('fast', 12, 'Fast EMA', 'int')\n...",
  "inputs": [
    { "var": "fast", "kind": "int", "name": "Fast EMA", "default": "12", "_val": 12 }
  ],
  "author": "Andrei Maltsev (Rawanga)",
  "license": "Apache-2.0",
  "homepage": "https://rawanga.es"
}
```

| Поле | Значение |
|------|----------|
| `kind` | Маркер типа файла (всегда `rawanga-trading-desk-strategy`) |
| `version` | Версия формата (сейчас `1`) |
| `key` | Внутренний id (образуется из заголовка) |
| `title` | Отображаемое имя |
| `source` | **Полный код стратегии** (главная часть) |
| `inputs` | Автоматически найденные параметры |
| `author` | Строка автора |
| `license` | Лицензия передаваемого кода |
| `homepage` | Ссылка на проект |

**Как делиться:**

1. Напишите стратегию и нажмите **Check**.
2. Нажмите **Export** → сохранится `MyStrategy.rwd.json`.
3. Передайте файл (чат, почта, репозиторий, gist).
4. Получатель нажимает **Import**, выбирает файл — готово. Стратегия появляется в
   его списке и готова к запуску.

> Машина получателя заново проверяет код в той же песочнице, которая блокирует
> `import`/`eval`/`exec` и доступ к файлам и сети, — так что переданный файл не
> может выполнить произвольный системный код. Это ограничивает возможности
> стратегии, но **не** гарантирует безопасность (см. предупреждение ниже). Для
> логики важно только поле `source` — остальные поля это метаданные.

> ⚠️ **Импорт чужих стратегий — на твой риск; импортируй только из источников,
> которым доверяешь.** Песочница блокирует доступ к системе, файлам и сети, но
> она не различает добросовестную стратегию и вредоносную: чужой код всё равно
> может быть ошибочным, вводящим в заблуждение или злоупотреблять разрешёнными
> вычислениями. **Всегда просматривай код в поле `source` перед импортом** и
> относись к любому импортированному `.rwd.json` как к недоверенному вводу. Автор
> не пишет и не проверяет чужие стратегии и не отвечает за них и за убытки,
> вызванные ими. По мере роста числа пользователей — прогоняй импортируемые
> стратегии на вредоносные/вирусные вставки перед запуском.

## 9. Компиляция

Работой в редакторе управляют три кнопки:

| Кнопка | Что делает |
|--------|------------|
| 🔎 **Check** | Проверяет код (безопасность + синтаксис) **и выполняет пробный прогон** на реальных барах. Показывает ошибки и сводку: бары, количество `long`/`short`/`exit`, число сделок. |
| ⚙ **Compile** | Та же проверка, затем **регистрирует стратегию в движке** под ключом. Она сразу становится доступна планировщику и бэктестеру (без перезапуска). |
| 🧷 **To chart** | Запускает код как **индикатор** и накладывает его вывод `plot`/`shape`/`hline` на текущий график. Сделки не регистрируются. |

Рекомендованный порядок:

1. Вставьте код.
2. Нажмите **Check** → исправляйте ошибки, пока не появится *«проверка пройдена»*
   и пробный прогон не будет выглядеть разумно.
3. Нажмите **Compile** → стратегия сохранится (сначала задайте имя в поле
   *Имя стратегии*). Ключ образуется из имени, например `My Strategy` → `my_strategy`.
4. Чтобы визуализировать индикатор, нажмите **To chart**.

Заметки:

- Имя должно быть уникальным; зарезервированные ключи `stv3`, `rawa_system` и
  `trend` заняты встроенными стратегиями.
- Скомпилированные стратегии сохраняются и регистрируются автоматически при
  запуске.
- Скомпилированную стратегию можно удалить из списка сохранённых.

## 10. Частые ошибки и подсказки

**1. Использование `and` / `or` / `not` для серий**

```python
# ❌ "The truth value of a Series is ambiguous"
cond = (r < 30) and (close > ma)

# ✅
cond = (r < 30) & (close > ma)
```

**2. Забытые скобки вокруг сравнений**

```python
# ❌ баг приоритета операторов
cond = close > ema_fast & volume > vol_ma

# ✅
cond = (close > ema_fast) & (volume > vol_ma)
```

**3. Использование циклов**

```python
# ❌ for ... запрещён
for i in range(len(close)):
    ...

# ✅ выразите векторно
mom = close / close.shift(10) - 1
```

**4. Забытое присваивание `inp(...)`**

```python
# ❌ вход объявлен, но не используется
inp('len', 14, 'Длина', 'int')

# ✅
length = inp('len', 14, 'Длина', 'int')
```

**5. `if` по серии**

```python
# ❌ неоднозначно
# if close > open: side = 1

# ✅
side = np.where(close > open, 1, -1)
```

**6. Сравнение пустой / начальной области**

Индикаторы вроде `sma(close, 200)` равны `NaN` на первых барах. Сравнения с `NaN`
дают `False` — это то, что нужно. Но если надо подставить значение, используйте `nz`:

```python
ma = nz(sma(close, 200), close)
```

**7. Настройка параметров**

Предпочитайте `inp(...)` вместо зашитых чисел — так можно оптимизировать без
правки кода. Параметры появляются в панели настроек после компиляции.

**8. Согласованность входов и выходов**

`entry('long', …)` также **разворачивает** шорт. Если нужен плоский выход, а не
разворот, используйте `exit(...)`. Осознанно выбирайте нужный вариант.

**9. Отрисовка только когда это индикатор**

`plot`/`shape`/`hline` безвредны в стратегии, но влияют на график только после
нажатия **To chart**. Сигналы дают `entry`/`exit`.

**10. Тестируйте на разных инструментах и таймфреймах**

Стратегия, красивая на одном инструменте, может быть шумом на другом. Прогоните
**Check** (и бэктестер) на нескольких рынках и таймфреймах, прежде чем доверять ей.

**11. Распаковка кортежа (`a, b = f(...)`) запрещена**

Песочница отклоняет присваивание с распаковкой кортежа при **Check**.
Индикаторы с несколькими значениями возвращают кортеж — берите части по индексу:

```python
# ❌ ошибка 'неизвестное имя' при Check
macd_line, macd_signal, macd_hist = macd(close)

# ✅
m = macd(close)
macd_line   = m[0]
macd_signal = m[1]
macd_hist   = m[2]

# так тоже можно:
hist = macd(close)[2]
```

**Полезные «кирпичики»**

```python
# Стоп на основе ATR как серия
stop_dist = atr(14) * 2

# Нормированный импульс
roc = close / close.shift(20) - 1

# Фильтр волатильности
calm = stdev(close, 20) < sma(stdev(close, 20), 50)

# Направление Supertrend
st = supertrend(10, 3.0)
st_dir = st[0]
entry('long',  (st_dir == 1) & (st_dir.shift(1) == -1))
entry('short', (st_dir == -1) & (st_dir.shift(1) == 1))

# Пробой полос Боллинджера
b = bb(close, 20, 2.0)
upper = b[0]
lower = b[2]
entry('long',  crossover(close, upper))
entry('short', crossunder(close, lower))
```
