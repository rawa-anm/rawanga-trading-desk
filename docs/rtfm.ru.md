# RTFM — Rawanga Trading Desk

> Read The Friendly Manual. Этот документ объясняет, что это за программа, как
> установить её на локальную машину, как запустить на сервере и как с ней
> работать. Есть на трёх языках: `rtfm.en.md`, `rtfm.es.md`, `rtfm.ru.md`.

---

## 0. Что это и для кого

**Rawanga Trading Desk** — портативное десктоп-приложение для:

- графиков свечей (таймфреймы 15m, 1h, 4h, 1d, 1w, 1M);
- технических индикаторов (MA/EMA, RSI, MACD, ATR, Supertrend, Bollinger, Donchian, ADX…);
- написания и бэктеста своих стратегий на Python;
- сигналов по сделкам/трендам с опциональными оповещениями (Telegram и/или e-mail);
- опциональной автоматической торговли на BingX (фьючерсы/swap) — **выключена по умолчанию**.

Технически это небольшой локальный веб-сервер (FastAPI) плюс интерфейс в
браузере. При запуске программа поднимает сервер **на твоём же компьютере** и
открывает интерфейс в браузере. Всё работает локально.

> ⚠️ **Назначение: индивидуальное, для одного пользователя.** Здесь **нет
> аккаунтов, нет входа, нет пароля на интерфейс, нет разделения пользователей.**
> Любой, кто может открыть веб-адрес программы, получает над ней полный
> контроль — включая включение реальной торговли, если ты её настроил.

## 2. Установка — портативный билд (обычный пользователь, своя машина)

Скачай архив под свою ОС со страницы Releases проекта:

- `RawangaTradingDesk-windows-x64.zip`
- `RawangaTradingDesk-macos-x64.tar.gz` (Intel) или `RawangaTradingDesk-macos-arm64.tar.gz` (Apple Silicon)
- `RawangaTradingDesk-linux-x64.tar.gz`

Распакуй куда угодно (Рабочий стол, USB-флешка, `D:\Apps`, `~/Apps`, …). В
папке — исполняемый файл и его окружение.

### Windows

1. Распакуй `.zip`.
2. Запусти `RawangaTradingDesk\RawangaTradingDesk.exe`.
3. SmartScreen может показать «Windows защитила ваш компьютер» (билд не подписан).
   Нажми **Подробнее → Выполнить в любом случае**.
4. Браузер с интерфейсом откроется сам.

### macOS

1. Распакуй `.tar.gz`.
2. Так как билд не нотаризован, macOS помечает его карантином. Сними его:
   ```bash
   xattr -dr com.apple.quarantine /путь/к/RawangaTradingDesk
   ```
3. Запусти бинарник `RawangaTradingDesk` внутри папки.
   Если macOS всё равно отказывается: **Системные настройки → Конфиденциальность
   и безопасность → Всё равно открыть**.
4. Браузер откроется сам.

### Linux

```bash
tar xzf RawangaTradingDesk-linux-x64.tar.gz
cd RawangaTradingDesk
chmod +x RawangaTradingDesk
./RawangaTradingDesk
```
Браузер откроется сам.

> Появившееся окно консоли — **это и есть программа**. **Закроешь окно —
> остановится программа.** Не закрывай его, пока работаешь.

## 3. Установка — из исходников (для разработчиков)

```bash
git clone <адрес-репозитория>
cd rawanga-trading-desk

python -m venv .venv
# Windows:  .venv\Scripts\activate
. .venv/bin/activate

pip install -r requirements.txt
python -m app.launcher
```

Браузер откроется на `http://127.0.0.1:<случайный_свободный_порт>/`.

Переменные окружения:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `RAWANGA_HOST` | `127.0.0.1` | адрес прослушивания (только локально) |
| `RAWANGA_PORT` | `0` (случайный свободный порт) | фиксированный порт, если нужен |
| `RAWANGA_DATA_DIR` | `./data` (рядом с программой), иначе каталог данных ОС | где хранятся твои данные |

## 4. Первый запуск и базовый сценарий работы

1. Запусти программу. Интерфейс откроется в браузере.
2. Выбери инструмент справа (например, `BTC`), таймфрейм — в панели над
   графиком (по умолчанию **1h**).
3. График загрузит свечи, объём и выбранные индикаторы.
4. Нижние ряды: кнопки стратегий, переключатели индикаторов, «Strategy editor»,
   «Strategy docs», вебхуки, настройки торговли.
5. Клик по инструменту открывает справа его **журнал сделок** (сделки за период,
   винрейт, лучшая/худшая, P/L).
6. **Редактор стратегий** (кнопка 🧩): загрузи сэмпл или напиши свою стратегию
   на Python → **Check** → **Compile** → **To chart**. Полный справочник — в
   кнопке **Strategy docs** (📘), на выбранном языке интерфейса.
7. **Язык интерфейса**: селектор в верхней панели (EN / RU / ES). Выбор
   запоминается на твоей машине.

## 5. Где живут твои данные и бэкапы

Все пользовательские данные — в **каталоге данных** (по умолчанию `./data` рядом
с программой; на машине, где эта папка недоступна для записи, — в каталоге
данных ОС: `%APPDATA%\RawangaTradingDesk` в Windows,
`~/Library/Application Support/RawangaTradingDesk` в macOS,
`~/.local/share/RawangaTradingDesk` в Linux).

| Файл | Содержимое |
|---|---|
| `tv.db` | база SQLite: инструменты, кэш свечей, параметры, журнал, настройки |
| `bx_secrets.enc` | API-ключи биржи + креды оповещений (зашифрованы) |
| `bx_secret.key` | мастер-ключ к предыдущему файлу |
| `bot.key` | токен Telegram-бота (опционально) |
| `usdtd_history.json` | вспомогательная история тренда |

**Бэкап:** скопируй весь каталог данных. **Перенос на другую машину:** скопируй
каталог данных вместе с папкой программы.

> Никогда не коммить и не передавай каталог данных: в нём твои ключи.

## 6. Оповещения (опционально)

Оповещения **выключены**, пока ты их не настроишь. Каналы независимы: можно
использовать Telegram, e-mail, оба или ни одного.

### Telegram

1. Создай бота через `@BotFather`, скопируй его токен.
2. Напиши своему боту любое сообщение, чтобы он мог тебе ответить; узнай свой
   chat id через `@userinfobot` (или аналоги).
3. В программе: **Настройки торговли → Bot token for trade alerts** и
   **Recipient TG id**. Сохрани.
4. Нажми **✈ Test alert** — оповещение должно прийти в Telegram.

### E-mail (письмо себе)

Программа шлёт оповещения **на один-единственный адрес — твой**, через твой же
SMTP-ящик. Это личная труба для оповещений, а не инструмент рассылок: один
получатель, без списков, без Cc/Bcc.

1. В программе: **Настройки торговли → E-mail alerts**.
2. Заполни SMTP host / порт / логин / пароль (для Gmail нужен **app-пароль**, а
   не обычный пароль) и адрес получателя (твой ящик).
3. STARTTLS используется для порта 587, неявный SSL — для 465.
4. Сохрани и нажми **✈ Test alert**.

## 7. Запуск на сервере (VPS / облако) — и предупреждение о безопасности

Запустить на сервере и открывать с другой машины *можно*. Но сначала внимательно
прочти это.

> ⚠️ **Безопасность — прочти перед размещением где-либо, кроме своего компьютера**
>
> 1. **У веб-интерфейса нет аутентификации.** Кто дотянется до порта — увидит
>    твои графики, поменяет настройки, отправит тестовые оповещения и (если ты
>    прописал ключи) включит и поведёт **реальную торговлю**.
> 2. **Твои креды лежат на хосте.** API-ключи биржи и креды оповещений хранятся
>    зашифрованными (Fernet) в `bx_secrets.enc`, **но мастер-ключ
>    `bx_secret.key` лежит в той же папке.** Для того, у кого есть доступ к
>    файловой системе (или кто получит снимок диска / бэкап), это, по сути,
>    **никакая не защита** — считай, что на облачном хосте ключи лежат открытым
>    текстом.
> 3. Как следствие: **не выставляй порт в открытый интернет.** Если всё же
>    размещаешь удалённо, как минимум:
>    - держи его привязанным к приватной сети и ходи через **VPN**
>      (например, Tailscale/WireGuard) или **SSH-туннель**
>      (`ssh -L 8080:127.0.0.1:8080 user@server`);
>    - либо поставь за **реверс-прокси с аутентификацией + TLS** и ограничь
>      фаерволом;
>    - шифруй диск сервера и используй отдельный ключ на бирже с минимальными
>      правами / без права вывода средств.

### Пример: запуск на сервере на фиксированном порту

```bash
# на сервере, внутри проекта (установка из исходников)
RAWANGA_HOST=127.0.0.1 RAWANGA_PORT=8080 python -m app.launcher
```

Затем заходи со своей машины через SSH-туннель:

```bash
ssh -L 8080:127.0.0.1:8080 user@твой-сервер
# теперь открой http://127.0.0.1:8080/ локально
```

### Пример: systemd-сервис (установка из исходников)

`/etc/systemd/system/rawanga-trading-desk.service`:

```ini
[Unit]
Description=Rawanga Trading Desk
After=network-online.target

[Service]
User=твойпользователь
WorkingDirectory=/opt/rawanga-trading-desk
Environment=RAWANGA_HOST=127.0.0.1
Environment=RAWANGA_PORT=8080
Environment=RAWANGA_DATA_DIR=/opt/rawanga-trading-desk/data
ExecStart=/opt/rawanga-trading-desk/.venv/bin/python -m app.launcher
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now rawanga-trading-desk
```

> Держи `RAWANGA_HOST=127.0.0.1` и ходи через VPN/туннель. Меняй на `0.0.0.0`
> только если полностью понимаешь, что выставляешь панель управления **без
> аутентификации**.

## 8. Редактор стратегий

- Открывается кнопкой **🧩 Strategy editor**.
- Пишешь Python; код исполняется в ограниченной песочнице (без `import`, `eval`,
  `exec`, `open`, доступа к файлам/сети, `for`/`while`, доступа к dunder).
- Доступный API: серии цен `open/high/low/close/volume`; `inp(...)`; индикаторы
  `sma, ema, rma, wma, stdev, highest, lowest, change, rsi, macd, bb, atr,
  supertrend, adx, donchian`; `crossover/crossunder`; `nz/na/series`;
  `entry/exit`; `plot/shape/hline`.
- Кнопки: **Check** (проверка + пробный прогон), **Compile (strategy)**
  (регистрация в движке), **To chart (indicator)** (нарисовать на графике),
  **Remove from chart**, **Export strategy**, **Import**.
- **Экспорт/импорт** — файл `*.rwd.json`, чтобы делиться стратегией.
- Полный справочник: кнопка **📘 Strategy docs** (EN/RU/ES).

## 9. Реальная торговля (BingX) — опционально и рискованно

Реальная торговля **выключена по умолчанию**. Чтобы включить, нужно: сохранить
API-ключи, задать фонд-пароль и явно включить реальный режим. Без всего этого
ни один ордер не отправится.

- Используй отдельный API-ключ с минимальными правами.
- Программа торгует только теми тикерами, что ты явно добавил в список
  «торгуемые тикеры».
- Торговля — под **твою** ответственность и **твоим** капиталом. ПО
  предоставляется «как есть»; это **не инвестиционная рекомендация**.

## 10. Обновление / удаление

- **Портативная:** замени папку программы на новую версию; свой каталог `data/`
  сохрани.
- **Из исходников:** `git pull` и `pip install -r requirements.txt`.
- **Удаление:** удали папку программы и (если хочешь чистый старт) каталог данных.

## 11. Диагностика проблем

| Симптом | Решение |
|---|---|
| Браузер не открылся | Открой вручную адрес из окна консоли (`http://127.0.0.1:<порт>/`). |
| Windows: «Windows защитила ваш компьютер» | Подробнее → Выполнить в любом случае (билд не подписан). |
| macOS: «нельзя открыть / повреждено» | `xattr -dr com.apple.quarantine <путь>` (см. §2). |
| Нет данных по инструменту | Проверь интернет; нажми **⟳ Refresh**. |
| Оповещения не приходят | Нажми **✈ Test alert**; проверь токен / chat id / настройки SMTP. |
| Порт уже занят | Задай `RAWANGA_PORT` свободным портом. |
| Где мои данные? | Папка `data/` рядом с программой (§5). |
